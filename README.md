  # LCARS OBSIDIAN THEME  —  MARK VIII
  
   Synthesizes three eras of LCARS design:
   
     · TNG (2364–2370)  — warm oranges, peach, lavender
     · Films (2371–2379) — deep navy, dense data panels
     · Picard (2399)    — cyan holographic, glows, brackets

   INSTALL: 
   Save as lcars-mkviii.css in .obsidian/snippets/
   
   ### Settings → Appearance → CSS Snippets → enable
   
   ### (Optional) Install "Style Settings" plugin to switch eras dynamically via Settings → Style Settings.

   ERA SWITCHER: Use Style Settings plugin dropdown, OR manually
   add class "lcars-tng" or "lcars-film" to the body element.
   Picard is the default.
